`inspect_template.py` で実測した値。別テンプレの場合は `generic-template.md` を参照。

| 定数 | 値 | 意味 |

| `L` | 484632 | 本文左端 |

| `TOP` | 1645920 | 本文上端（リード文の下） |
| — | 6627812 | フッタ位置。本文は 6100000 までに収める |

## フォントとサイズ

全て `メイリオ`（`<a:latin>` `<a:ea>` `<a:cs>` の3つに指定する。1つでも欠けると環境により別フォントになる）。
`sz` は1/100pt単位。

| 要素 | sz | 太字 | 色 |
|---|---|---|---|
| スライドタイトル（idx12） | 2000 | ● | NAVY |
| リード文（idx13） | 1150 | | GRAY |
| セクション見出し `＜…＞` | 1300 | ● | NAVY |
| カードヘッダ | 1300 | ● | WHITE |
| 本文・箇条書き | 1000〜1100 | | GRAY |
| 表ヘッダ | 1000〜1050 | ● | WHITE |
| 表セル | 900〜1000 | | GRAY |
| 注釈 `※` | 900 | | GRAY |
| 大きな数字 | 2400 | ● | NAVY / GRAY |

**行あたりの文字数の目安**: 日本語全角1文字の幅 ≒ フォントpt。
テキストボックス幅 4,000,000 EMU・11pt なら約28文字、10pt なら約31文字。
行高 ≒ pt × 1.4。これで事前にカード高さを見積もれる。

## レイアウト対応

| レイアウト | 名前 | 用途 | 供給するもの |
|---|---|---|---|
| `slideLayout1` | 7_ユーザー設定レイアウト | 表紙 | ロゴ、Confidentialバッジ |
| `slideLayout3` | ユーザー設定レイアウト | 中扉 | 平行四辺形の飾り、下線 |
| `slideLayout5` | 4_基本 | **本編（これを使う）** | 上部バー、タイトル枠(idx12)、リード文枠(idx13)、CONFIDENTIAL、VRAINロゴ、Copyrightフッタ、ページ番号 |

本編スライドは `slideLayout5` 以外使わない。レイアウトがヘッダ・ロゴ・フッタを全部供給するので、
こちらが書くのは本文領域の図形だけになる。

**重要**: 本編スライドの `.rels` はレイアウトしか参照していない（画像を持たない）。
だからXMLを丸ごと書き直しても安全。逆にAppendixのスライドは画像を抱えているので**絶対に書き直さない**。

## スライドの型と実測座標

以下のコードは `import deck_lib as d` 前提で、読みやすさのため `d.` を省略している。
実際に書くときは `d.card(...)` `d.L` のようにモジュール経由で参照すること（SKILL.md §2参照）。

### 2カード型（現状と課題／検査概要と仕様）
```
card(i, L,       TOP, 4370832, h, "＜左＞", [...])
card(i, 5074920, TOP, 4370832, h, "＜右＞", [...], header_fill=RED)
banner(i, L, 4892040, W, 868680, [...])
```
h は中身次第で 2560320〜3360000。カード下端とバナー上端は 300000 EMU 程度空ける。
右カードのxが `5074920` なのは、左カード右端 4855464 に 219456 の溝を足した位置。
`cols(2)` がちょうどこの値を返すので、コードでは `cols()` を使う。

### フロー型（工程の流れ）
```
flow(i, [(label, fill, textcolor), ...])   # y=1783080, 箱1627632×960120, ピッチ1911096
```
5箱が上限。6箱以上は文字が潰れるので2段にするか工程をまとめる。

### ポイント3行型（`＜本構成のポイント＞`）
```
textbox(..., L, 3200400, W, 320040, [P(R("＜本構成のポイント＞", sz=1300, b=1, color=NAVY))])
point_row(i, L, 3584448, W, 749808, "ラベル", ["本文1行目", "本文2行目"], fill=LTGRAY)
# 以降 y += 841248、fillは LTGRAY / WHITE を交互に
```
ラベルは全角14文字程度まで。超えると2行になって帯を割る。

### 表型
```
table(sid, L, 1627632, widths, [header_row([...])] + zebra([...], specs), [hdr_h] + [row_h]*n)
```
widths の合計を `W`(8961120) に合わせる。行高は最小値なので、列幅だけ設計して高さは任せる。
`<a:tblPr/>` は空のまま（テーブルスタイルを指定せず、セルごとに塗りを置く）。

### ガント型
```
gantt(i, rows, months, year_spans)   # x=L, y=1737360, ラベル列2011680, 行高480000
```
16か月 × 5行が収まる上限。それ以上は四半期単位に粗くする。

### 効果型（Before→After）
```
shape(...,  822960, 1783080, 3383280, 1691640, fill=LTGRAY)   # Before
shape(..., 4434840, 2331720,  822960,  594360, fill=NAVY, prst="rightArrow")
shape(..., 5486400, 1783080, 3383280, 1691640, fill=LTBLUE, line=NAVY)  # After
# 下段カード3枚: x = 484632 / 3502152 / 6519672、幅2834640、y=4315968、高さ1417320
```
